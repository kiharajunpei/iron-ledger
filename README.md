# 鉄の帳簿 — Iron Ledger

毎日の筋トレメニューと記録帳。**オフラインで動くPWA**。

## 使い方
1. スマホのブラウザでこのサイトを開く
2. **iOS**: 共有ボタン → 「ホーム画面に追加」／**Android**: メニュー → 「アプリをインストール」
3. 以降はホーム画面のアイコンから起動。**圏外でも起動して記録できる**

## 中身
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（1枚。ビルド不要・依存なし） |
| `sw.js` | Service Worker。アプリ本体とフォントをキャッシュして圏外起動を可能にする |
| `manifest.webmanifest` | ホーム画面へのインストール定義 |
| `icon-*.png` | アイコン（192 / 512 / maskable / apple-touch） |

## データの置き場所
**記録はこの端末の `localStorage` にだけ入る。** サーバへは一切送らない。

- `ledger.cache` — 記録本体
- `ledger.queue` — 未確定の操作（単体版では即座に空になる）
- `ledger.prefs` — 設定（レベル・体重・ローテのオフセット）

つまり **端末間の同期は無い**。ブラウザのサイトデータを消すと記録も消える。

## メニューの出典
YouTube「男磨き完全版シリーズ・ボディメイク編」の構成をプログラム化したもの。

- **初心者（7日で1周）** — ベンチプレス週3回を軸に、Day1/3/5 にベンチが来て48〜72時間間隔を守る
- **初中級（5分割）** — 胸／背中／肩／足／腕

ローテーションはカレンダーではなく**「今日より前にジムへ行った日数」**で進む。行けなかった日があっても部位が飛ばない。

### 動画から変えた点
週5メニューをそのまま7日へ展開すると週93セットになったので、**同じ動きの重複だけ**を削って83セットにした。

- Day3「インクラインサイドレイズ」削除（サイドレイズと同じ動き）
- Day6「プーリーロー」削除（Day2にある）
- Day1「ダンベルプレス」→ **インクラインダンベルプレス**（ベンチと重複していた上に上部に効かないため）

胸18セット/週のうち上部狙い9セット＝50%。アプリの「週あたりのセット数」カードで部位別の過不足が見える。

## 計算
- 推定1RM = `重量 × (1 + 回数 / 30)`（Epley式）
- 週セット数は多関節種目の主働筋を1.0、補助部位を0.5で換算
- トレ日の区切りは **UTC+0（ガーナ時間）**

## 更新
`index.html` を編集して push するだけ。`sw.js` の `CACHE` の値（`iron-ledger-v1`）を上げると、
古いキャッシュを捨てて新しい版が確実に配られる。
