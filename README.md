# 鉄の帳簿 — Iron Ledger

毎日の筋トレメニューと記録帳。**オフラインで動くPWA**。

## 使い方
1. スマホのブラウザでこのサイトを開く
2. **iOS**: 共有ボタン → 「ホーム画面に追加」／**Android**: メニュー → 「アプリをインストール」
3. 以降はホーム画面のアイコンから起動。**圏外でも起動して記録できる**

画面は下のタブで4つ。

| タブ | 中身 |
|---|---|
| **今日** | 今日のメニュー・推奨重量・記録デッキ・今日のセット |
| **積み上げ** | 累計の数字・カレンダー・週ごとのボリューム・全履歴 |
| **分析** | 推定1RMの推移・強さの物差し・部位別セット数（実績と予定）・卒業判定 |
| **設定** | プログラム／体重／日付の切り替わり／タイマー／書き出し・読み込み |

## 中身
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目 |
| `data.js` | 固定データ（プログラム・部位対応・種目メタ・強さの物差し） |
| `app.js` | 本体のロジック |
| `sw.js` | Service Worker。上の4枚とフォントをキャッシュして圏外起動を可能にする |
| `manifest.webmanifest` | ホーム画面へのインストール定義 |
| `icon-*.png` | アイコン（192 / 512 / maskable / apple-touch） |

ビルド不要・依存なし。編集して push すれば出る。

## データの置き場所
**記録はこの端末の `localStorage` にだけ入る。** サーバへは一切送らない。

- `ledger.sets` — 記録本体
- `ledger.prefs` — 設定（プログラム・体重・バー・タイムゾーン・タイマー・ローテのオフセット）

つまり **端末間の同期は無い**。ブラウザのサイトデータを消すと記録も消える。
→ 設定タブの **「書き出す」** でJSONを保存し、新しい端末で **「読み込む」**。重複は自動で飛ばす。

旧版（`ledger.cache` ＋ `ledger.queue`）のデータは**初回起動時に自動で引っ越す**。未送信キューの追加・削除も反映してから移す。

## メニューの出典
YouTube「男磨き完全版シリーズ・ボディメイク編」の構成をプログラム化したもの。**中身は変えていない。**

- **初心者（7日で1周）** — ベンチプレス週3回を軸に、Day1/3/5 にベンチが来て48〜72時間間隔を守る
- **初中級（5分割）** — 胸／背中／肩／足／腕

ローテーションはカレンダーではなく**「今日より前にジムへ行った日数」**で進む。行けなかった日があっても部位が飛ばない。

### 動画から変えた点
週5メニューをそのまま7日へ展開すると週93セットになったので、**同じ動きの重複だけ**を削って83セットにした。

- Day3「インクラインサイドレイズ」削除（サイドレイズと同じ動き）
- Day6「プーリーロー」削除（Day2にある）
- Day1「ダンベルプレス」→ **インクラインダンベルプレス**（ベンチと重複していた上に上部に効かないため）

胸18セット/週のうち上部狙い9セット＝50%。分析タブの「週あたりのセット数」で部位別の過不足が見える。

## 計算
- 推定1RM = `重量 × (1 + 回数 / 30)`（Epley式）
- 週セット数は多関節種目の主働筋を1.0、補助部位を0.5で換算
- 総ボリューム = `重量 × 回数` の合計。自重種目は体重を足す
- トレ日の区切りは**設定で選ぶ**（既定＝この端末の0時／アクラ UTC+0／日本 UTC+9）

## 推奨重量と「強さの物差し」
種目ごとに「いまの自分ならこの重さ」を出す。出し方は2通りで、**自分の記録があるほうが優先**。

1. **自分の記録から**（記録が1回でもある種目）
   直近3回の推定1RMの最高値を基準に、目標レップ帯の %1RM を掛ける。
   前回トップセットで上限回数まで回せていたら、基準を **+2.5%** して「次の一手」を出す。
2. **一般的な目安から**（記録がまだ無い種目）
   `体重あたりの1RM × 体重` → 同じく %1RM を掛ける。レベルはベンチの記録から推定（無ければ「初級」）。

記録の有無にかかわらず、**「入門／初級／中級／上級／エリート」の5段階の重量が常に並んで出る**（その日のレップ帯の真ん中で計算）。
いまの自分の位置が金枠で光り、数字を押すとその重さが入る。
つまり画面には**「次の一手（自分の記録から）」と「目安（世間の基準）」が同時に**出ている。

**回数→%1RM** は NSCA の負荷表（1回=100% / 5回=87% / 8回=80% / 10回=75% / 12回=70%）に15回以上を足して線形補間したもの。

**体重あたりの1RM** は `data.js` の `EX[].std`。入門／初級／中級／上級／エリートの5段階で、**男性の一般的な目安**。
Strength Level・Fitness Volt など公開されている強さ基準の中央値あたりを取った。

> ⚠️ **ビッグ3（ベンチ・スクワット・デッドリフト）は出典がおおむね一致するが、補助種目はばらつきが大きい。**
> サイドレイズやケーブル系の「中級」はサイトによって倍ちがうこともある。順位づけ・目安の道具として見ること。
> 自分の記録が貯まった種目は、目安ではなく自分の記録から計算するようになる。そっちのほうが当たる。

**単位の決まり**（`EX[].u`）:

| 値 | 意味 | 例 |
|---|---|---|
| `bb` | バーベル等の合計重量 | ベンチプレス 60kg |
| `db` | **ダンベル片手**の重量 | サイドレイズ 5kg（＝5kgを両手） |
| `bw` | 自重＋追加した重り | チンニング 自重+5kg |
| `mc` | マシン・ケーブルの表示値 | ラットプルダウン 40kg |

強さの物差しも同じ単位で比べている（ダンベル種目の基準は片手あたり）。

## 入力の刻み
重量のステップは種目ごと（バーベル ±2.5/±5、ダンベル ±1〜2、マシン ±5/±10）。
回数は ±1/±5。**どちらも4つのボタンを2×2に置いている**——横1列だと狭い端末で「−2.5」が見切れるため。

## インターバルタイマー
セットを記録すると自動で走る。既定の秒数は種目ごと（コンパウンド180秒／アイソレーション60〜90秒）で、
設定タブから固定値にもできる。`+30秒`・`スキップ`、終わったら音とバイブ。

## 入力について
重量と回数は**大きい数字をタップすると専用のテンキー**が開く。`<input type="number">` は使っていない。

> iOS の数値入力は、全角で打つと文字が消える・既存の値に割り込んで `70` に `75` を打つと `7570` になる・
> 範囲外だと黙って元に戻る、が同時に起きる。**打った数字と違う値が確定する**のはこれが原因だった。
> ±ボタンも `touch-action:manipulation` が無いと連打でダブルタップ拡大が発動して画面が飛ぶ。

## 更新
編集して push するだけ。`sw.js` の `CACHE` の値（`iron-ledger-v2`）を上げると、
古いキャッシュを捨てて新しい版が確実に配られる。**ファイルを増やしたら `SHELL` にも足すこと。**
